# HOLOSPACE — Futuristic Multiplayer Mixed-Reality

Transform ordinary smartphones into windows to a shared holographic world using rear cameras and mixed reality.

## Overview
HOLOSPACE enables multiple users holding their smartphones horizontally to see real surroundings through the rear camera while virtual holograms are anchored to the physical world. Users can scan real objects on a table, reconstruct 3D geometries and textures, anchor persistent holograms, and collaboratively interact from different physical perspectives in real time.

For full architecture, technical details, and documentation, see [holospace/README.md](holospace/README.md).

## Quick Start
```bash
# 1. Start Server
cd holospace/server
npm install
node server.js

# 2. Start Client
cd holospace/client
npm install
npm run dev
```
Or double-click `holospace/start.bat` on Windows.
